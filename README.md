# Cown — نظام إدارة المطعم

تطبيق ويب عربي/إنجليزي لإدارة نقطة البيع والطلبات والطاولات والمطبخ والمنيو والمخزون والمشتريات والمصروفات والموظفين والشفتات والتقارير. الواجهة الرئيسية هي `/`، ويعمل المسار `/restaurant` كعنوان بديل.

## التشغيل والتجربة المحلية

```sh
npm install
npm start
```

افتح `http://localhost:3000` وسجّل الدخول محليًا برمز المدير `6026` أو رمز الكاشير `2233`. هذه الرموز للاستخدام أثناء التطوير المحلي فقط؛ لا تنشر هذا الوضع أو بياناته كحل إنتاجي. تُحفظ البيانات التجريبية في `localStorage` على المتصفح نفسه.

## تسجيل الدخول والنشر الإنتاجي

يتطلب إصدار الإنتاج إعداد Supabase للمصادقة؛ إذا لم تُضبط الإعدادات، يعرض التطبيق تنبيه إعداد بدل السماح بالدخول. لتهيئته:

1. أنشئ مشروع Supabase وشغّل `supabase/schema.sql` في SQL Editor.
2. أنشئ حساب المالك في Supabase Authentication، وأبقِ التسجيل العام مغلقًا.
3. أضف ملف المالك إلى جدول `employees` باستخدام الاستعلام النموذجي أدناه، مع استبدال البريد والاسم:

   ```sql
   insert into public.employees (id, full_name, role)
   select id, 'Restaurant Owner', 'owner'
   from auth.users
   where lower(email) = lower('owner@example.com')
   on conflict (id) do update
     set full_name = excluded.full_name, role = excluded.role, active = true;
   ```

4. أضف `VITE_SUPABASE_URL` ومفتاح Supabase publishable/anon إلى إعدادات بيئة البناء. لا تستخدم مفتاح service-role في تطبيق المتصفح.
5. أنشئ حسابات الموظفين في Supabase Authentication وأضف ملفاتهم النشطة في `employees` مع الأدوار المطلوبة.
6. شغّل `npm run build` وانشر محتويات `dist/` على استضافة تدعم تطبيقات SPA عبر HTTPS.

Supabase مستخدم لتسجيل الدخول والتحقق من دور الموظف فقط حاليًا؛ بيانات المطعم تبقى في `localStorage` ولا تتزامن بين الأجهزة. لا تستخدم هذا الإصدار لتشغيل عدة أجهزة أو كمخزن بيانات مركزي حتى تضاف مزامنة خلفية.

## البناء والاختبارات

```sh
npm test -- --run
npm run build
```

التطبيق قابل للتثبيت كـ PWA بعد نشره عبر HTTPS. استخدم زر «تثبيت التطبيق» إذا عرضه المتصفح، أو قائمة Chrome ثم «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية». يوفّر عامل الخدمة غلافًا أساسيًا للعمل دون اتصال، لكن تسجيل الدخول والبيانات تحتاج المتصفح نفسه.
